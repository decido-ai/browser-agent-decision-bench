# Data notice

`steps-final.zip` (password `mind2web`) contains `steps-final.jsonl`, derived from the test splits (test_task, test_website, test_domain) of
[Multimodal-Mind2Web](https://huggingface.co/datasets/osunlp/Multimodal-Mind2Web) by the OSU NLP Group, released under
the OpenRAIL license. Each step keeps the task description, website, domain, recorded action, a text rendering of the
page and up to 50 candidate elements; screenshots are not included. Use of this file is subject to the original dataset's
license and its use restrictions. Following Mind2Web's request, please do not post the unzipped file online.
